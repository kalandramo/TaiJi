## 0. 一句话速查

| 场景 | 最少需要 |
|---|---|
| 单 agent 飞书长连接 | `TAIJI_MODEL_NAME` `TAIJI_MODEL_API_KEY` `TAIJI_MODEL_BASE_URL` + `FEISHU_APP_ID` `FEISHU_APP_SECRET` |

| 群聊里响应 @ | 再加 `TAIJI_FEISHU_BOT_OPEN_ID`（多 agent 时自动获取，不必设） |

## 6. 工作区文件（非环境变量，但可覆盖普通键）

`taiji serve --config <path>` 指定的文件可提供普通键，
但**保留键一律跳过**（`internal/config/guard.go` 的 `ReservedKeys` /
`CredentialKeys` / `ReservedPrefixes`）——工作区是 agent 可写区域，
允许它覆盖控制值等于开提权路径。

工作区**不能**覆盖的键（摘要）：

- 控制值：`TAIJI_INSTRUCTION`、`TAIJI_SKILLS_ROOT`、`TAIJI_SKILL_TOOL_PROFILE`、`TAIJI_AGENTS`
- 凭据：`FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_VERIFICATION_TOKEN`、`FEISHU_ENCRYPT_KEY`
- 前缀族：`TAIJI_MCP_HEADERS_*`

> `FEISHU_VERIFICATION_TOKEN` / `FEISHU_ENCRYPT_KEY` 是 webhook 形态的遗留：
> webhook 已移除（只保留长连接），故当前**无读取方**，但保留在保护集合里
> ——移除会削弱将来重加 webhook 时的保护基线（见 `internal/channel/feishu/config.go` 的说明）。
