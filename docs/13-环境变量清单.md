## 0. 一句话速查

| 场景 | 最少需要 |
|---|---|
| 单 agent 飞书长连接 | `TAIJI_MODEL_NAME` `TAIJI_MODEL_API_KEY` `TAIJI_MODEL_BASE_URL` + `TAIJI_AGENTS`（**一条**） |
| 多 agent（每 agent 一个飞书应用） | 上述模型三项 + `TAIJI_AGENTS`（多条，含 `parent=` 等隔离字段） |
| 按用户管控工具 | 再加 `TAIJI_RBAC` |

> **`TAIJI_AGENTS` 是 agent 与飞书凭据的唯一入口**（2026-10-02 起）。
> 单 agent 与多 agent 用**同一个变量**——区别只在条目数：
>
> ```
> 单 agent： TAIJI_AGENTS="name=assistant,app_id=cli_xxx,app_secret=yyy"
> 多 agent： TAIJI_AGENTS="name=root,...,app_secret=s1;name=bill,...,parent=root"
> ```
>
> 下游按 `len(specs) > 1` 判别走单值还是 per-agent 路径，
> 与「配置写在哪个变量」无关。

### 2.1 bot open_id 的获取策略（含一次回归的修正）

`/open-apis/bot/v3/info` 是**网络调用**。把它设为启动硬依赖会让
「凭据暂时失效」「离线调试」「纯私聊部署」都起不来——而这些场景
**不需要** open_id（只有群聊 @ 判定用）。故按 agent 数分流：

| 情形 | 行为 |
|---|---|
| 获取成功 | 用获取到的映射（无论单/多 agent） |
| 多 agent + 失败 | **fail-fast**——每个 bot 的 open_id 不同，手填单值服务不了 |
| 单 agent + 失败 + 有手填值 | **回退**到 `TAIJI_FEISHU_BOT_OPEN_ID`（群聊 @ 判定仍可用） |
| 单 agent + 失败 + 无手填值 | **警告**（群聊会被拒，私聊不受影响），不拒绝启动 |

策略实现在 `cmd/taiji/main.go` 的 `decideBotOpenID`（纯函数，有单测）。

## 6. 工作区文件（非环境变量，但可覆盖普通键）

`taiji serve --config <path>` 指定的文件可提供普通键，
但**保留键一律跳过**（`internal/config/guard.go` 的 `ReservedKeys` /
`CredentialKeys` / `ReservedPrefixes`）——工作区是 agent 可写区域，
允许它覆盖控制值等于开提权路径。

### 6.1 工作区文件真正有用的键

| 键 | 效果 |
|---|---|
| `WORKSPACE_NAME` | `workspaceID()` 的第二优先级回退（`TAIJI_WORKSPACE_ID` > 本文件 > `"default"`）。它决定**RBAC 主体 ID 的 workspace 段**——改它会让已配的 `user:` 条目失配 |
| `TAIJI_MODEL_BASE_URL` | 可覆盖环境变量（`main.go` 从 loaded 读） |

> `TAIJI_MODEL_NAME` 虽也被读（`main.go`），但它**同时在 `ReservedKeys` 里**，
> 写在工作区文件会被跳过——实际能覆盖的只有 `BASE_URL`。

### 6.2 保留键（写了会被跳过并告警）

- **控制值**（`ReservedKeys`）：`TAIJI_INSTRUCTION`、`TAIJI_SKILLS_ROOT`、
  `TAIJI_SKILL_TOOL_PROFILE`、`TAIJI_AGENTS`
- **凭据**（`CredentialKeys`）：**当前为空**（2026-10-02）——
  四个原 `FEISHU_*` 键已全部移除
- **前缀族**（`ReservedPrefixes`）：`TAIJI_MCP_HEADERS_*`

> `TAIJI_AGENTS` 是当前**唯一**的飞书凭据载体（内含各 agent 的 ak/sk），
> 它在 `ReservedKeys` 里，受工作区覆盖保护。
> 该保护由 `internal/config/agents_test.go` 的
> `TestReservedKeys_TAIJI_AGENTS` / `TestMergeWorkspaceEnv_SkipsTAIJI_AGENTS` 锁定。

> `CredentialKeys` 保留了变量本身（虽为空）作为**将来新增渠道凭据的挂点**——
> `isReserved` 已在引用它，加键即生效。
> **代价（明示）**：将来重加 webhook 时需重新发现「验签口令属凭据、
> 必须受工作区保护」这一点。
